# ET Software Studio Homebrew tap

```sh
brew install etsoftwarestudio/tap/promptshelf
brew install --cask etsoftwarestudio/tap/open-freematics-emulator
```

| Cask | App |
| --- | --- |
| `open-freematics-emulator` | [Open Freematics Emulator](https://github.com/ETSoftwareStudio/open-freematics-emulator): open-source app for the Freematics OBD-II Emulator MK2 (unofficial) |

| Formula | Tool |
| --- | --- |
| `promptshelf` | [PromptShelf](https://github.com/ETSoftwareStudio/promptshelf): save, fill and share prompts; installs the `shelf` command |

Formulae and casks here are updated automatically by each project's release workflow.
